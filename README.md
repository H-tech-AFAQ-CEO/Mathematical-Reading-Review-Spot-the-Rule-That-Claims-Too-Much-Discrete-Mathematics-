# Reading Rules Verification — Discrete Mathematics (Levin, 3rd ed.)

Prepared by **Afaq Ahmad**

## What this is

A screening submission that checks 8 proposed "reading rules" for mathematical
language (e.g. *only if*, *necessary and sufficient*, *proof by contradiction*)
against their source quotations in *Discrete Mathematics: An Open Introduction*
by Oscar Levin (3rd edition, CC BY-SA 4.0).

Each rule is marked:
- **C** — the quote supports the rule as written.
- **F** — the rule contradicts the quote, or adds a claim the quote does not
  establish. A short correction is given for every F.

## Result summary

| # | Rule | Verdict |
|---|------|:---:|
| 1 | Proof by cases (Q / ¬Q) need not cover every possibility | **F** |
| 2 | "P is sufficient for Q" means Q ⇒ P | **F** |
| 3 | Proving the converse alone does not prove the original | **C** |
| 4 | Quantifying a free variable is not enough to make it a statement | **F** |
| 5 | "P only if Q" means Q ⇒ P | **F** |
| 6 | One counterexample disproves a universal statement | **C** |
| 7 | An implication with a false hypothesis is false | **F** |
| 8 | The contrapositive reverses P/Q and negates both | **C** |
